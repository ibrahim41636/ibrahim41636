# Saudi market keyword map (selorin.co)

Working list of the searches Saudi clients use, mapped to the page that should rank for each.
Arabic first: most Saudi B2B searches for these services are in Arabic. Volumes are not yet
measured; confirm and re-rank from Google Search Console (Performance → Queries, country = Saudi
Arabia) once the property has a few weeks of data, then update this file.

Rules: one primary keyword per page (no two pages competing for the same query); the primary
keyword appears in the Arabic `seoTitle`, H1/lead and first paragraph; city names appear naturally,
never as keyword lists; no claims of accreditation or approval that Selorin does not hold.
