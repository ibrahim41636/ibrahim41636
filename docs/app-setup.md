# تطبيق سيلورين: طلب الخدمات ومتابعتها

الموقع نفسه أصبح **تطبيقاً قابلاً للتثبيت** (PWA) على آيفون وأندرويد، ويضم:

| الميزة | الرابط |
|---|---|
| طلب خدمة (النموذج الحالي مع رفع المرفقات) | `/ar/request/` |
| متابعة الطلب برقم الطلب والبريد | `/ar/track/` |
| لوحة الفريق لتحديث حالة الطلبات | `/ar/admin/` |

الحالات: تم الاستلام ← قيد المراجعة ← تم إرسال العرض ← قيد التنفيذ ← مكتمل / مغلق.
عند تحديث الحالة من اللوحة يمكن إرسال بريد للعميل تلقائياً (عبر Resend).

## خطوات التفعيل (مرة واحدة)

### 1. قاعدة البيانات D1 (لحفظ الطلبات ومتابعتها)
1. Cloudflare ← **Storage & Databases** ← **D1 SQL Database** ← **Create database**.
2. الاسم: `selorin-leads` ← الموقع: أقرب منطقة (Europe أو Asia) ← **Create**.
3. انسخ **Database ID** من صفحة القاعدة وأرسله للمطوّر، ليضيفه إلى `wrangler.toml`.
   (لا يُربط من اللوحة فقط، لأن كل نشر جديد يمسح الربط غير الموجود في الملف.)
4. في القاعدة افتح **Console** والصق محتوى `migrations/0001_leads.sql` ثم **Execute**،
   ثم محتوى `migrations/0002_tracking.sql` ثم **Execute**.

### 2. رمز دخول لوحة الفريق
1. Workers & Pages ← **ibrahim41636** ← Settings ← Variables and Secrets ← **+ Add**.
2. Type: **Secret** · Name: `ADMIN_TOKEN` · Value: كلمة سر طويلة (24 حرفاً أو أكثر).
3. **Deploy**. شارك الرمز مع فريق المبيعات فقط.

### 3. التثبيت على الجوال
- **آيفون (Safari):** افتح selorin.co/ar ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **أندرويد (Chrome):** افتح selorin.co/ar ← القائمة ⋮ ← **تثبيت التطبيق**.

## المرحلة الثانية: النشر في App Store وGoogle Play
بعد تجربة النسخة الحالية مع العملاء، تُغلَّف بالكود نفسه (Capacitor) وتُنشر في المتجرين، مع
إشعارات فورية بتحديثات الطلب وتذكير بمواعيد تجديد التصاريح. تحتاج حينها:
- حساب **Apple Developer** (99 دولاراً سنوياً) باسم المنشأة، ويتطلب رقم D-U-N-S.
- حساب **Google Play Console** (25 دولاراً مرة واحدة).
