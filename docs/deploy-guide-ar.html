من الكود إلى موقع يعمل على https://selorin.co مع نماذج طلب الخدمة التي تُرسَل إلى sales@selorin.co. الصور في هذا الدليل توضيحية مبسطة، وقد تختلف تفاصيل واجهات GitHub وCloudflare قليلًا عند التنفيذ، لكن أسماء الأزرار والخطوات مطابقة.

مجانية وتلقائية
لماذا Cloudflare Pages وليس GitHub Pages؟ لأن GitHub Pages يستضيف صفحات ثابتة فقط. أما نماذج طلب الخدمة فتحتاج خادمًا صغيرًا يتحقق من الطلب ويحمي من الرسائل المزعجة ويرسل البريد إلى sales@selorin.co، وهذا ما توفره Cloudflare Pages Functions مجانًا. يبقى GitHub مكان حفظ الكود، وCloudflare مكان التشغيل.

خطوات الدليل

  1. إيصال الكود إلى GitHub (الطريقة الأسهل أو اليدوية)
  2. دمج التعديلات في الفرع الرئيسي main
  3. إضافة النطاق selorin.co إلى Cloudflare
  4. تغيير خوادم الأسماء (Nameservers) لدى مسجّل النطاق
  5. إنشاء مشروع Cloudflare Pages وربطه بـ GitHub
  6. ربط selorin.co وwww بالمشروع
  7. قاعدة بيانات الطلبات D1
  8. تفعيل الإرسال إلى البريد عبر Resend
  9. الحماية من الرسائل المزعجة (Turnstile)
  10. الاختبار النهائي وطريقة التحديث لاحقًا

3إضافة النطاق selorin.co إلى Cloudflare

حساب Cloudflare مجاني. هذه الخطوة تجعل Cloudflare مسؤولًا عن إعدادات DNS للنطاق.

  1. أنشئ حسابًا في dash.cloudflare.com (يُفضَّل ببريد الشركة).
  2. اضغط Add a domain (أو Onboard a domain) واكتب selorin.co.
  3. اختر Quick scan for DNS records ثم الخطة Free.
  4. مهم جدًا: راجع قائمة السجلات المكتشفة وتأكد من وجود سجلات MX الخاصة بالبريد (التي يعمل بها sales@selorin.co حاليًا) قبل المتابعة.
  5. ستعرض Cloudflare خادمَي أسماء (Nameservers) خاصين بك. انسخهما للخطوة التالية.

4تغيير خوادم الأسماء لدى مسجّل النطاق

مسجّل النطاق هو الجهة التي اشتريت منها selorin.co (مثل GoDaddy أو Namecheap أو غيرها).

  1. سجّل الدخول لدى المسجّل وافتح إدارة النطاق selorin.co.
  2. ابحث عن Nameservers واختر Custom (خوادم مخصصة).
  3. احذف الخوادم القديمة وألصق خادمَي Cloudflare من الخطوة 3، ثم احفظ.
  4. ارجع إلى Cloudflare واضغط Check nameservers. التفعيل عادة يستغرق من دقائق إلى 24 ساعة، وتصلك رسالة عند اكتماله.

7قاعدة بيانات الطلبات D1

8تفعيل الإرسال إلى sales@selorin.co عبر Resend

Resend خدمة إرسال بريد (الخطة المجانية تكفي في البداية). يُرسَل الطلب من website@selorin.co إلى sales@selorin.co، مع رسالة تأكيد للعميل.

  1. أنشئ حسابًا في resend.com، ثم Domains ← Add Domain، وأدخل selorin.co. اختر منطقة قريبة إن أمكن.
  2. ستظهر سجلات DNS (‏TXT للتحقق وDKIM، وMX/TXT لنطاق فرعي مثل send). إن ظهر زر Auto configure مع Cloudflare فاستخدمه، وإلا انسخ كل سجل إلى Cloudflare ← DNS ← Records ← Add record.
  3. انتظر حتى تصبح الحالة Verified.
  4. API Keys ← Create API Key بصلاحية Sending access، وانسخ المفتاح (يظهر مرة واحدة).
  5. في Cloudflare: مشروع selorin-website ← Settings ← Variables and Secrets ← Add، النوع Secret، الاسم RESEND_API_KEY، والقيمة هي المفتاح.

9الحماية من الرسائل المزعجة (Cloudflare Turnstile)

بديل مجاني وغير مزعج لـ CAPTCHA يحمي نماذج طلب الخدمة.

  1. في Cloudflare: Turnstile ← Add widget. الاسم Selorin forms، والنطاقات selorin.co و www.selorin.co، والنوع Managed.
  2. ستحصل على مفتاحين. أضفهما في Variables and Secrets (الخطوة 8):
    • Site Key ← متغير عادي (Plaintext) باسم PUBLIC_TURNSTILE_SITE_KEY
    • Secret Key ← سر (Secret) باسم TURNSTILE_SECRET
  3. أعد النشر من Deployments ← ⋯ ← Retry deployment لأن مفتاح الموقع يُضمَّن وقت البناء.

10الاختبار النهائي، وطريقة التحديث لاحقًا

قائمة التحقق
  1. https://selorin.co يفتح بقفل HTTPS، و www يعمل أيضًا.
  2. https://selorin.co/ar/ يفتح النسخة العربية من اليمين إلى اليسار.
  3. أرسل طلبًا تجريبيًا من طلب خدمة ← أجهزة رصد الغبار.
  4. تصل رسالة بعنوان [New Service Request] – … إلى sales@selorin.co، ورسالة تأكيد إلى بريد المرسل.
  5. الروابط القديمة للموقع السابق تُحوَّل تلقائيًا إلى الصفحات الجديدة.
